# 大冯老师的央视频下载助手

油猴（Tampermonkey）用户脚本，在 **tv.cctv.com** 视频页面注入下载面板，自动探测真实画质档位，并在浏览器内完成 MP4 转封装。

## 功能特性

| 能力 | 说明 |
|------|------|
| 自动探测画质 | 进入央视视频页后自动识别可选清晰度档位 |
| 浏览器内转封装 | 「直接下载 MP4」采用内联 mux.js 在页面上下文完成 fMP4 → MP4，无需任何外部工具 |
| 验证码防刷 | 验证码由腾讯云 COS 存储桶远程下发（随机无规律、可随时轮换），不写死在脚本里 |
| 公众号解锁 | 关注「数智化教学大冯老师」并发送关键词后获取验证码 |

## 安装方法

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。
2. 新建用户脚本，将 `大冯老师的央视频下载助手.js` 全文粘贴保存；或将该 `.js` 文件拖入 Tampermonkey 管理页完成安装。
3. 打开任意 `tv.cctv.com` 视频页（如 `https://tv.cctv.com/xxxx/xxxx.shtml`），页面右下/指定区域出现下载面板即可使用。

## 使用说明

- 在视频页点击下载面板中的「直接下载 MP4」，脚本会拉取各档位地址并在浏览器内转封装后触发下载。
- 首次使用需通过验证码：按面板提示关注公众号并获取验证码填入即可（验证码远程下发，失效时运营方一键轮换）。

## 安全说明

- 本脚本已做基础安全扫描：**未发现硬编码的密钥、Token 或内嵌明文凭据**。
- 验证码通过腾讯云 COS 公共读取地址远程下发，脚本仅含该公共 URL，不携带任何私密配置。
